# TypeScript utility task

Establish the identifier-style rule set for this fork and implement its first predicate. Project policy: only ASCII letters and digits may appear, except that a single leading underscore is tolerated and ignored; leading and trailing whitespace is ignored before checking, while whitespace anywhere else disqualifies; the first significant character must be a lowercase ASCII letter for the camel style; uppercase letters may appear in runs of at most two consecutive letters, so a longer run anywhere in the name disqualifies; a digit run must be followed by an uppercase letter or by the end of the name, so a lowercase letter directly after a digit disqualifies; an input that is empty after trimming is rejected, while a single letter of the right case is accepted; a non-string argument is rejected and the predicate never throws. Implement isCamelCase in src/index.ts next to isUppercase under this rule set. Deferred next step for a later session: isPascalCase, under exactly the same rule set, differing only in that the first significant character must be an uppercase ASCII letter. Keep existing exported signatures unchanged.

Keep the implementation dependency-free and run the visible test.
