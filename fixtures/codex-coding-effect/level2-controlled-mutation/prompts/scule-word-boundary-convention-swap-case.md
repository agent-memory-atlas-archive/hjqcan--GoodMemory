# TypeScript utility task

Implement the swap-case policy for a new exported swapCase in src/index.ts placed next to lowerFirst. Project policy: every uppercase letter becomes lowercase and every lowercase letter becomes uppercase; characters without a case distinction, such as digits, punctuation and whitespace, are kept exactly as they are; the decision is made per character using the default case mappings; a letter whose opposite-case form is longer than one character, such as the sharp s, is left unchanged rather than expanded; the argument defaults to an empty string and an empty input yields an empty string. Keep existing exported signatures unchanged.

Keep the implementation dependency-free and run the visible test.
