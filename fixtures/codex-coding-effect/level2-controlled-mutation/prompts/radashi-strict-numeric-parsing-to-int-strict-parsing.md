# TypeScript utility task

Record and implement the strict numeric parsing rule for the number coercers in this fork. What was tried and failed: toInt and toFloat leaned on the built-in prefix parsers, which silently accepted text with trailing letters as its leading digits, read a hexadecimal prefix and comma-grouped thousands as numbers, and cut exponent notation off after the mantissa; imported data was corrupted before anyone noticed, so prefix parsing is banned in this fork. Replacement rule: a string is a number only when, after trimming whitespace, the entire text is an optional sign, one or more digits, an optional fraction that has digits on both sides of the point, and an optional exponent; anything else, including hexadecimal prefixes, digit separators of any kind, and infinite-value words, yields the default; a finite number input is used as is, and toInt truncates it toward zero; a non-finite number, a boolean, a nullish value, an array, an object, or a symbol yields the default; the default is zero unless a defaultValue argument is given. Apply this to toInt in src/number/toInt.ts and keep the exported signature unchanged.

Keep the implementation dependency-free and run the visible test.
