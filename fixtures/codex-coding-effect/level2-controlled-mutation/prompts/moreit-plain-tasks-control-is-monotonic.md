# Python utility task

Add a function is_monotonic(iterable) to more_itertools/more.py, next to is_sorted, and list it in the module's __all__. It returns True when the items are entirely non-decreasing or entirely non-increasing, and False otherwise. Equal neighbours are allowed in either direction.
