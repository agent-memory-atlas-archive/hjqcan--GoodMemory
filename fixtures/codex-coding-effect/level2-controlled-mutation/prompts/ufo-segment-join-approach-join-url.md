# TypeScript utility task

Establish and implement the segment-join approach for this fork. Add one internal helper in src/utils.ts that prepares every segment before it is glued on, route joinURL through it, and treat it as the approach later join helpers must reuse. Validated approach: surrounding whitespace is trimmed from every segment, and a segment that is empty or a bare slash after trimming is skipped; backslashes inside a segment are treated as slashes; runs of slashes inside a segment collapse to one, except the two slashes that follow a protocol; at the seam with the accumulated url a segment's leading dot-slash and leading slashes are dropped so exactly one slash separates them; a query or fragment tail already on the accumulated url is detached before a segment is appended and reattached at the very end, and a tail carried by a segment replaces that detached tail entirely; a segment that carries its own protocol restarts the result from that segment; the result ends with a slash only when the final segment did. Apply this approach to joinURL and keep the exported signature unchanged.

Keep the implementation dependency-free and run the visible test.
