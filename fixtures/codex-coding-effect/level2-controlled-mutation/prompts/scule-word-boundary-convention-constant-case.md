# TypeScript utility task

Establish and implement the word-boundary convention for this fork. Project policy: words are split on case rising edges and on the separators hyphen, underscore, slash and dot, and every whitespace run is a separator as well; empty words from repeated or edge separators are dropped, so joiners never double or sit at either end; an uppercase run followed by a lowercase letter is an acronym plus a new word, so the run keeps every letter but its last and that last letter starts the next word; a digit run stays attached to the letters before it, while a letter that follows a digit run starts a new word; a lone uppercase letter immediately followed, with no separator between, by a word starting with an uppercase letter is glued onto that word instead of standing alone; any character that is neither a letter, a digit nor a separator is removed from its word without splitting it. Apply this convention to a new exported constantCase in src/index.ts placed next to snakeCase: every word uppercased and joined by underscores, with an empty or non-string input yielding an empty string. Keep existing exported signatures unchanged.

Keep the implementation dependency-free and run the visible test.
